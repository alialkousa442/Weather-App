# 🌤️ Weather App

A sleek, modern, and responsive Weather Application built with JavaScript, Webpack, and modern CSS (Glassmorphism). It provides real-time weather data, dynamic condition-based icons, and robust error handling.

---
## 🔗 Live Demo

👉 [View Live Application](https://alialkousa442.github.io/Weather-App/)

---


## 🚀 Features

- **Glassmorphism UI:** Modern, clean, and elegant translucent glass interface.
- **Dynamic Weather Icons:** Scalable and precise condition mapping using an Exact Match Dictionary (`exactIconMap`) for accurate visual representation.
- **Temperature Unit Toggle:** Seamlessly switch between Celsius (°C) and Fahrenheit (°F).
- **Robust Error Handling:** Clear user feedback for empty search inputs, network issues, or invalid city names.
- **Fully Responsive:** Optimized for both desktop and mobile viewports.

---

## 🛠️ Built With

- **JavaScript (ES6+):** Core application logic, async/await API fetching, and DOM manipulation.
- **Webpack:** Module bundler for managing assets and building production-ready code.
- **OpenWeatherMap API:** External API for fetching real-time weather data.
- **CSS3:** Custom styling featuring Flexbox, Grid, and Glassmorphism effects.
- **GitHub Pages:** Live hosting and deployment pipeline.
